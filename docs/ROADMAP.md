## 1. 新施工顺序（按价值×依赖重排）

### N1 台账闭环（原 M6，提到最前）✅ 已完成（提交见 log；测试基线 446）
台账是"三事实层"唯一缺的一层；它下游（RP 注入、伏笔欠账、下一幕提案）已经半接入，边际价值最高。
- ✅ **台账页**（LedgerPage）：待确认队列（recap 提案统一汇入，逐条确认/编辑/驳回+溯源原文）、伏笔欠账视图、正典时间线（按日分组+溯源）、驳回区（append-only 只标记不删，可恢复）；类型筛选标签
- ✅ **时间点快照**（`flow/snapshot.ts` 纯逻辑+测试）：`ledgerSnapshot` 只吃 confirmed、时间升序、类型轮转取样防单类挤爆、maxChars 预算裁切并声明；`upto` 支持"截至某刻"参照
- ✅ **伏笔欠账**（`foreshadowDebt`/`debtText`）：大纲 foreshadows（埋）× confirmed foreshadow 台账（收），归一化包含式匹配 + status=paid 直通；欠账注入共创访谈与下一幕提案提示词
- ✅ **提示词注入端口**：`nextScenePrompt`/`outlineCoachPrompt` 新增 `facts` 入参（prompts 库保持零运行时依赖，文本由调用方 `ledgerFacts` 预生成）
- 验收：一幕 RP → recap 勾选提案采纳（已有）→ 台账页最终裁决 → 共创访谈/下一幕提案提示词内可见该事实 + 伏笔欠账

### N2 站内 RP 引擎补全（原 M5 收尾）✅ 已完成（测试基线 504）
- ✅ **组装管线 v2（优先级预算队列）**：`rpAssemble` 分段（主指令/本幕指引/世界书前后/角色卡/画像/台账快照/范例/AN/摘要/历史），裁序 范例→世界书→画像→台账→旧历史（keepTurns 兜底），保护段（主指令/指引/卡/AN/摘要）永裁不动；`ledgerBlock` 台账快照注入 system（TrialPage 用 ledgerFacts 装配）
- ✅ **组装预览升级**：分段 token 预览条（色块悬停看段名/处置/被裁原因）+「查看提示词」列出各段 token 与最终发送全文；预算/预留回复在线可调；overflow 如实警示
- ✅ **滚动摘要**：`planRollingSummary`（阈值 2500 tok、保 8 条最近、折叠段以 char 收尾保证交替干净）+ `rollingSummaryPrompt`（analyzer 合并旧摘要→滚动链）；流式结束自动触发、手动「🗜 压缩前情」；失败不打断聊天；摘要随会话落库（rollingSummary 字段），跨幕 prevSummary 链打通
- ✅ **会话持久化**：站内 RP 稳定落定自动 upsert 本幕工作会话（testing，含 cast/nodeId/滚动摘要），刷新/换页「续写」恢复；本幕会话面板：回放（摘要+正文截断 6000）、状态切换（试跑中/正典/弃稿）；复盘保存复用同一行不重复建档
- ✅ **swipe + 编辑**：重生成＝追加候选（不覆盖，←/→ 回滑）；任意回合 ✎ 编辑 / ✕ 删除；自动落库只在稳定态（流式中间态不写库）
- ✅ **matcher 补 sticky/cooldown**：确定性前向重放状态机（触发→sticky 窗→冷却→重触发），sticky=0&cooldown=0 逐位退化为原行为；`matcher-timed.test.mjs` 锁语义（含副键联合、constant 豁免、冷却压制直接命中）
- 验收：长一幕 → token 条可见、历史自动压缩、关页重开会话还在、swipe 可回退 ✓（手测路径：站内试跑面板）

### N3 分歧闭环收尾（原 M7 剩余边角）✅ 已完成（测试基线 507）
- ✅ **注入纠偏继续站内演**：复盘偏差列表「→ 拟为纠偏」一键取句 + 自由纠偏输入框；`composeAuthorNote`（纯逻辑+测试）把指令写进 author's note 区重建 rpSetup，下一句回复生效、对话上下文无损；在场最多 3 条自动退旧、可清空；诚实边界：只影响站内 RP（ST 侧提示手工贴 AN）
- ✅ **幕状态机联动**：应用节拍标记后检测全拍完成 → 出现「🔒 本幕已演毕：标记已锁定」（tested→locked 硬规则沿用）；锁定文案与剧情世界书退场语义对齐（退场以节拍 done 为准，锁定防误编辑）
- ✅ **链路核对**：跑偏 → 站内 RP「带回复盘」→ 三选一（注入纠偏续演 / 反向修纲+应用 / 接受+采纳提案）→ 修纲后重打包自动接回旧对话 → 台账提案入裁决队列 → 快照/欠账回流共创与下一幕提案——UI 无断点；修纲生效路径有明确提示文案
- 验收：演示"跑偏→改纲→顺纲续写→台账更新"完整链路 ✓（手测路径全部在 ST 试跑页 + 台账页）

### N6 RP 剧场（用户新需求 2025-07，插队交付）✅ 已完成（测试基线 536）
脱离 SillyTavern 的站内「真聊天区」：工作区新页签 **RP 剧场**。
- 选幕 + 选人物卡（可无卡→自动旁白卡）+ 选用户画像 → 按**整部大纲**组装开聊：greeting 含本场目标与节拍、author's note、世界书每轮重扫、**台账快照+伏笔欠账注入**、上一场前情自动继承
- **自动台账**：滚动摘要升级为场记 digest 双产出（`rollingDigestPrompt` + `sanitizeDigest` 纯逻辑+测试）——历史折叠点自动抽取已发生事实，直接落台账「待确认队列」（带溯源到工作会话）；另有「🧾 结算本场」按钮全量提取。裁决仍在台账页，AI 只提案
- 「带回复盘」在剧场内等同结算（只抽事实）；节拍命中复盘/反向修纲仍走 ST 试跑页（分工写明在页面文案里）
- 复用 RpRunner/工作会话语义，与 ST 试跑页同一份落库结构，两页数据互通
- **重复收敛（同月）**：ST 试跑页的「站内试跑」面板与 rpSetup 全套已删除——站内开聊（含纠偏注入、自动台账）全部归剧场；ST 试跑专管导包/导回/复盘四件套。三条一次性交接打通两页（`flow/handoff.ts`，localStorage 投递+项目作用域+10 分钟 TTL）：剧场「带回复盘」→试跑页自动复盘；试跑「续写」→剧场自动选幕选卡开台；复盘纠偏→剧场预填
