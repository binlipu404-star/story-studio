## 1. 新施工顺序（按价值×依赖重排）

### N1 台账闭环（原 M6，提到最前）✅ 已完成（提交见 log；测试基线 446）
台账是"三事实层"唯一缺的一层；它下游（RP 注入、伏笔欠账、下一幕提案）已经半接入，边际价值最高。
- ✅ **台账页**（LedgerPage）：待确认队列（recap 提案统一汇入，逐条确认/编辑/驳回+溯源原文）、伏笔欠账视图、正典时间线（按日分组+溯源）、驳回区（append-only 只标记不删，可恢复）；类型筛选标签
- ✅ **时间点快照**（`flow/snapshot.ts` 纯逻辑+测试）：`ledgerSnapshot` 只吃 confirmed、时间升序、类型轮转取样防单类挤爆、maxChars 预算裁切并声明；`upto` 支持"截至某刻"参照
- ✅ **伏笔欠账**（`foreshadowDebt`/`debtText`）：大纲 foreshadows（埋）× confirmed foreshadow 台账（收），归一化包含式匹配 + status=paid 直通；欠账注入共创访谈与下一幕提案提示词
- ✅ **提示词注入端口**：`nextScenePrompt`/`outlineCoachPrompt` 新增 `facts` 入参（prompts 库保持零运行时依赖，文本由调用方 `ledgerFacts` 预生成）
- 验收：一幕 RP → recap 勾选提案采纳（已有）→ 台账页最终裁决 → 共创访谈/下一幕提案提示词内可见该事实 + 伏笔欠账

### N2 站内 RP 引擎补全（原 M5 收尾）
- **组装管线 v2（优先级预算队列）**：卡/世界书/**台账快照(N1)**/大纲引导/滚动摘要/近期消息/AN，超预算按序裁 + **组装预览升级**：各段 token 占用条 + 被裁内容可见
- **滚动摘要**：超过 N 轮的远期历史自动 analyzer 摘要（滚动链），跨幕 prevSummary 已有、接上
- **会话持久化**：站内 RP 落 RPSession（含 nodeId/cast），刷新可续写；会话列表/回放/状态（testing/canon/abandoned）
- **swipe**：重生成改为旁存多候选（不覆盖），编辑/删除消息
- **matcher 补 sticky/cooldown**（站内世界书语义与 ST 对齐；含测试）
- 验收：长一幕 → token 条可见、历史自动压缩、关页重开会话还在、swipe 可回退

### N3 分歧闭环收尾（原 M7 剩余边角）
- 复盘三选一的中间路：**注入纠偏指令并继续站内 RP**（把纠偏写进 AN 区）
- 幕状态机联动：试跑通过→建议 tested/锁定；节拍全 done→已演标记（剧情世界书自动退场依赖它）
- 验收：演示"跑偏→改纲→顺纲续写→台账更新"完整链路（即 v0.1 的 M7 验收场景）

### N4 ST 导演桥 Lite（计划外，源自 L3/L5 探索；**仅在 N1+N3 后痛点仍存才做**）
- sidecar（复用 dist-test 纯逻辑）+ 页外 ST 扩展（`generate_interceptor` 正门注入）：场内自动换拍、按台账/复盘裁判自动 disable 已演条目
- 前置实证已齐（1.18 源码：chats API/third-party 扩展/组打分语义）；预算 1~2 天 + 每次 ST 大版本 ~半天维护
- 验收：ST 场内导演指令随拍自动切换、拍毕自动作废

### N5 打磨（原 M8）
- 项目 bundle 导出（大纲 md/json + 卡 json + 世界书 + transcript + 台账 zip）
- RP→小说化直通（transcript 送 st-novel-tool 流程的桥/或轻润色）
- 加固：外观抽取 6 卡人工分类兜底 UI；无头 e2e（可选）；Tauri 壳按需拍板
- 验收：全流程 demo 一部短篇带走
