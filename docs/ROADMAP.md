### P3 场记 agent（7 工具白名单 + 活动流）✅
- `chatTools`（`ai/client.ts`）：非流式多轮循环上限 4 轮防成本失控；端点不认 tools（首轮 400/422/404）→ `ToolsUnsupportedError` → **自动降级**纯摘要 digest（正典照写、节拍标记不可用）并标注
- 工具面恰 7：`read_outline / get_progress / mark_beat(仅副本) / where_is_story / next_step / read_ledger / append_ledger(仅本剧组正典)`——**物理上不存在主纲写工具**，「主纲只能去大纲工作台改」由工具表保证；未知工具/坏参数返回纠错文本喂回模型
- 「现在整理」按钮 + 活动流逐步展示；SSE 分片累积器与执行器全在 `flow/agent.ts` 纯逻辑（Node 30 测试）

### P4 本地文件夹自动写盘（可选）✅
- File System Access API：目录句柄存 Dexie `meta` 表（v4）；用户预建空文件夹→「📁连接」一次授权
- 每轮稳定落定覆盖写 `<清洗名>-<id前6>.jsonl`（串行链+400ms 去抖+`createWritable`→`close` 原子换）；同名冲突由恒定 id 后缀消解
- 错误分流：文件夹丢失→重选 / 权限过期→「重新连接」一键手势 / AbortError=取消静默；Firefox/Safari 无 FSA → 明示并退回每剧组手动 ⬇ 导出

### 已知边界（诚实声明）
- 多标签页同剧组写同一文件夹：后落盘者覆盖，不做跨页锁
- 刷新后 FSA 权限回 `prompt`：需用户点一次「重新连接」（规范如此）
- `append_ledger` 直写本剧组正典（用户决定）；作品级台账裁决在剧场右栏「台账」面板人工在环
- 节拍命中复盘仍属 ST 试跑页；沙盒组无剧本复盘不适用（用 jsonl 导出）
- 同一剧组开在两个浏览器页签：后开页签整组**只读**并出横幅（navigator.locks 互斥，同浏览器内生效）；锁不可用的浏览器不拦——**请勿双开同一剧组**
- 进度记忆走 localStorage：只存 id 与小段草稿（≤4000 字），浏览器隐私模式/清站点数据即失效
